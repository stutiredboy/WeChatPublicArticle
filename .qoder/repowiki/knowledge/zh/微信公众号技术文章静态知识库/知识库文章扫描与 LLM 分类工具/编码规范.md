- 所有命令行入口使用 Click 的 `@click.command()` 装饰器注册，参数通过 `@click.option()` 声明，错误信息统一通过 `rich.console.Console` 打印彩色日志。
- 数据模型统一使用 Pydantic `BaseModel` 定义，字段通过 `Field(description=...)` 提供中文描述，便于 LLM 提示词与 JSON Schema 复用。
- 外部配置（LLM 密钥、模型名、base_url）通过 `dataclass(frozen=True)` 的 `LLMConfig.from_env()` 类方法从环境变量加载，缺失时抛出明确异常。
- 文件 I/O 统一通过 `pathlib.Path` 操作，编码固定为 utf-8，读取失败时返回空字符串或兜底值而非抛错。
- LLM 调用采用 httpx 直连 `/chat/completions` 端点，配合重试+指数退避与 `_fallback_meta` 兜底机制，失败时自动归入 life/待分类 并标记置信度为 0。
