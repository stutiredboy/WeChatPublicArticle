模块以 `__main__.py` 为入口，实际逻辑委托给 `cli.py` 中基于 Click 构建的命令组（scan/todo/add/extract/index/show/stats）。数据流呈单向管道：`scanner.py` 遍历目录生成 `Article` 列表 → `extractor.py` 读取文章内容并通过 httpx 调用 LLM 生成 `ArticleMeta` → `writer.py` 写出 JSON 索引与 Markdown 文档。`models.py` 用 Pydantic BaseModel 统一定义 Article 与 ArticleMeta；`config.py` 集中管理 ROOT 路径、.env 加载、LLMConfig 数据类及 SKIP_DIRS/SKIP_MD 白名单；`taxonomy.py` 从 taxonomy.yaml 加载 Category/Taxonomy 结构并生成供 LLM 提示词使用的分类说明文本。依赖方向严格单向：cli → scanner/extractor/writer/taxonomy/config/models，各子模块之间无循环引用。
