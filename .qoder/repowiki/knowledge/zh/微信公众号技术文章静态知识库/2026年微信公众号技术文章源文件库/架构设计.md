纯静态内容仓库，无构建脚本或框架代码。目录以 `YYYY/MM/` 两级时间维度组织，每个子目录对应一篇独立文章：文章主文件为同名 `.md`，图片统一放在同目录下的 `images/` 子目录中，通过相对路径 `![](images/xxx.png)` 引用。部分特殊文章采用复合结构：如 `insurance_article/`、`hyper_hl_article/`、`middle_school_fragility/`、`领导未回祝福文章/` 等目录内同时包含 `.md`、`.html`、`.pdf`、Python 转换脚本（`convert_to_html.py`、`manual_convert.py`、`pack_zip.py`）及打包产物（`.zip`），用于将 Markdown 转换为公众号 HTML 或生成 PDF。整体依赖方向单一：Markdown 源文件 → images 资源 → 可选的 Python 脚本 → HTML/PDF 输出，不存在模块间代码依赖。
